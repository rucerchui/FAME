# FAME Project Page

Static academic project page for **FAME: Benchmarking Foundation and Large Language Models for Few-Shot Medical Image Segmentation** (arXiv:2607.27856).

## Local preview
Open `index.html` directly in a browser, or serve the folder with any static server.

## Deploy to GitHub Pages
1. Create a repo (e.g. `FAME` or `<user>.github.io`).
2. Put all files (`index.html`, `static/`) at the repo root (or a `docs/` folder).
3. Repo Settings → Pages → Source = `main` branch, `/root` (or `/docs`).
4. The site will be live at `https://<user>.github.io/<repo>/`.

## Structure
- `index.html` — the page
- `static/css/style.css` — styling
- `static/js/main.js` — scroll reveal, stat count-up, BibTeX copy
- `static/images/` — figures (converted from the paper/supplementary PDFs)

## Editing
- Update authors, links, and numbers directly in `index.html`.
- All external links (Paper / Code / 🤗 Dataset) are already wired.
